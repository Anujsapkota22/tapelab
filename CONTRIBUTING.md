# Contributing to TapeLab

Thanks for helping make backtests easier to inspect. For a bug report or feature idea, open an issue with a minimal example, expected behavior, observed behavior, and relevant data assumptions. Do not attach private or licensed market data.

## Pull requests

- Keep changes focused and explain the behavior or accounting rule they affect.
- Include or update documentation for user-visible changes.
- For execution or metric changes, show a small hand-checkable example and explain its assumptions.
- Do not include live credentials, proprietary datasets, or claims of investment performance without reproducible sources and context.
- Discuss large interface changes in an issue before investing in implementation.

Automated test coverage is an early roadmap item. As it is added, contributions should include regression coverage for corrected behavior. Until then, reviewers should state what manual checks they performed and avoid implying that unrun checks passed.

By participating, you agree to follow the project's [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are licensed under the MIT license in this repository.
