# Security policy

TapeLab is a research library and does not connect to brokers or handle account credentials. Please do not include API keys, private trading records, or other secrets in issues or pull requests.

For a suspected vulnerability that could affect users of the package, report it privately through GitHub's repository security advisory feature if available. Include the affected version, impact, and a minimal reproduction. Avoid public disclosure until maintainers have had a reasonable opportunity to investigate and prepare a fix.

Supported version: the latest published release. The project is pre-1.0 and makes no guarantee of backward compatibility.
