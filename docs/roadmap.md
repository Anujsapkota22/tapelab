# Roadmap

TapeLab is at the first public milestone. Priorities will follow reproducible user reports and review from people who use the engine for research.

## Near term

- Add focused automated coverage for timing, fees, slippage, allocation transitions, and invalid data.
- Add a small set of hand-calculated accounting examples so reported values can be independently checked.
- Improve error messages and document behavior for irregularly spaced bars.
- Publish versioned releases with a changelog and a clear compatibility policy.

## Later, based on community input

- Optional benchmark data adapters with source and licensing notes.
- Multiple assets and portfolio-level cash allocation.
- Additional execution models behind explicit interfaces.
- Visual reports that show equity, drawdown, and fills without implying predictive value.

These are proposals, not promises. The project will prioritize correctness and understandable assumptions over feature count.
